# 横截面因子 × 缠论择时 Pilot V1（CONTAMINATED_STRESS_ONLY）

## 1. 研究定位

本协议复制的是“低维、先验、线性、成本后、严格对照和前向冻结”的研究纪律，
不是复制任何机构的私有因子或产品收益。当前本地数据只能用于工程验收和非对称证伪；
无论历史结果多好，均不得表述为独立样本外证据、可交易 alpha 或上线依据。

原因已经冻结：

- 可用行情是当前口径的日线前复权数据，不是 PIT 未复权成交价；
- 缺少 PIT 申万行业和 PIT 自由流通市值，不能声称行业/规模中性；
- 旧状态缓存只投影了 4–8 态，且由最终文件长度过滤过股票；
- 2021–2026 年样本已被既有选股与主升浪研究反复查看；
- 本地 manifest 与实际文件截止不一致，不能作为审计依据。

所有产物必须带 `CONTAMINATED_STRESS_ONLY`，并输出输入文件 SHA256 manifest 与
`data_limitations.json`。任何限制项为 false 时，正式升级必须 fail closed。

## 2. 唯一主规格（运行前冻结，不做网格挑选）

- 冻结区间：`2022-01-01` 至 `2026-06-09`；状态缓存之后的行情不进入 pilot。
- 股票池：冻结使用 `scripts/_output/surge_candidates/panel.parquet` 的 distinct symbol 清单，
  而不是由某日状态值反推清单；它仍是受最终文件长度影响的污染宇宙。排除科创板/北交所；
  每个决策时点距首个 bar 至少 250 个全市场交易 session；非 ST；最近 60 个全市场
  session 至少 57 日有有效成交；ADV20 按全市场 session 计算（停牌日成交额记 0），
  且至少 5,000 万元。
- 不使用前复权绝对价格阈值；成交额原始字段单位按 Tushare 的千元处理。
- 因子一：`mom_120_20 = log(close[t-20] / close[t-120])`。
- 因子二：`lowvol_60 = -std(log(close/close[-1]), 60)`。
- 每个决策日先按 ADV20 五分位分层；每层分别做 1%/99% winsorize 和百分位排名；
  `score = 0.5 * rank(mom_120_20) + 0.5 * rank(lowvol_60)`。这只能称“流动性分层”，
  不能称行业、规模或风险中性。
- 每个交易周最后一个交易日收盘决策，下一交易日开盘执行；Top 20、每槽约 5%、
  组合预留 0.5% 现金缓冲、无杠杆，少于 20 只时余量留现金。
- `F`：因子 Top 20。
- `FC`：先固定同一份因子 Top 20，再对**新开仓**应用缠论门；只有状态
  `{5, 6, 7, 8}` 放行。被否决的槽位留现金，不用第 21 名以后股票回填。
  已有股票若仍在因子 Top 20，不因状态门关闭而强平；掉出 Top 20 时按正常调仓退出。
- `R_liq`：20 个预先固定的连续随机种子，分别匹配 F 的 ADV20 五分位数量抽取 20 只，
  以每日净收益的等权均值组成对照；不得从种子中挑选结果。
- `FGR`（factor + gate random）：保留同一份 F Top 20，并在每个决策日随机形成与 FC
  相同的目标持仓数量；20 个固定种子平均。它用于控制“少买股票、多持现金”的主要
  暴露效应，但随机路径与真实状态路径的留存/换手仍可能不同，因此 `FC-FGR` 不是纯粹的
  状态身份因果效应。
- 不使用 9/10 强平、主升 onset、delay5、市场宽度门、止损或参数优化。

缠论缓存只允许读取 `symbol, dt, regime` 三列。缺行、缺股票、非 5–8 态全部拒绝
新买，但“拒绝”仅代表 fail-closed，不能解释为已正确识别其他状态。

## 3. 时间线与成交约束

- 状态/因子层只有 `decision_dt` 及当时已知字段，严禁 `next_open`、未来收益和标签。
- 意图层记录 `decision_dt/target/entry_allowed/reason`，不含成交价。
- 成交层单独记录 `decision_dt/exec_dt/open/fill_price/status/cost`；收盘信号只能在
  下一交易日开盘成交。
- 买入遇停牌或近似开盘封涨停时取消，权重留现金；卖出遇停牌或近似开盘封跌停时
  继续持有并逐日重试，期间收益和风险照常计入。
- 当前只有前复权日线，因此整手、最低佣金、历史 tick、IPO 涨跌停和真实开盘冲击
  只能近似，不能据此报告可成交容量或生成实盘委托。

初始名义资金固定 1,000 万元。成本模型是透明、可压力测试的研究假设：佣金双边
2.5bp（最低佣金 5 元）、过户/经手合计 0.1bp、
卖出印花税在 2023-08-28 前 10bp、之后 5bp；基础滑点每边 10bp，冲击为
`15bp * sqrt(participation / 1%)`，参与率分母使用决策时已知 ADV20，单笔最多成交
ADV20 的 5%。同时固定输出 2 倍成本压力结果。成本参数不代表券商报价或生产撮合承诺。

## 4. 输出与非对称判定

允许输出 F、FC、R_liq 的全日历净值、年度描述统计、主动收益、IR、最大回撤、
周收益中位数、10% 截尾均值、最好周贡献、换手、现金、成交失败、成本和参与率。
统计量只作 descriptive，不作确认性 p 值宣传。

以下任一成立即可否决或重写经济假设（机器产物 `pilot_decision.json` 必须逐项给值）：

- 2 倍成本后 F 或 FC 相对 R_liq 主动收益不为正；
- 周主动收益中位数不为正；
- 最好 10 个正主动收益周贡献超过全部正主动收益的 50%；
- 至少 4 个日历年度主动收益为负；
- FC 相对 F 既没有提高 IR，也没有降低最大回撤；
- 工程语义测试或资金守恒失败。

工程准入单独要求：同一脚本/协议/输入 SHA 与种子重复运行的研究表必须逐字节一致；
因子 prefix invariance；`decision_dt=t` 只能在 `exec_dt=t+1` 成交；非调仓日不得免费
恢复等权；卖出受阻时逐日重试且实际持仓仍不得超过 20；状态读取调用链只能出现白名单
三列。完整状态缓存、100只×20个截断时点状态镜像和 research/live 候选镜像尚未满足，
因此 V1 的工程升级门固定为失败。

若全部表现良好，唯一允许的结论是“值得补齐 PIT 数据并建立正式协议”。

## 5. 正式研究解锁条件

依次完成后才能建立 V2：

1. 建立不可覆盖的全库 manifest、PIT 上市/退市/ST 宇宙并补齐退市股票；
2. 获取未复权价与 PIT 复权因子，按日期实现板块/ST/IPO 涨跌停规则；
3. 获取 PIT 行业与自由流通市值，完成行业和规模暴露约束；
4. 取消整文件长度过滤，生成 0–10 全状态因果缓存并通过 prefix invariance；
5. 冻结新协议，启动至少 52 周只追加、不可回填的真实前向 paper 日志。

V1 的历史收益不得参与 V2 参数选择。
