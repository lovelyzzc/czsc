## 结论

回测应先回答“缠论门控相对同一纯因子路径是否产生增量”，再看策略自身的绝对收益。
按注册 40bps 路径，historical validation 的第一判据 FC − F 为：

- 累计收益差：-14.69 个百分点；
- 精确相对财富收益：-13.88%；
- 几何年化超额：-6.03%；
- 信息比率：-0.64；
- 主动最大回撤：-29.08%；
- 主动周胜率：45.60%。

周主动收益点估计在经济上不利，但注册 HAC 95% 区间跨零，不能声称统计显著。当前
证据仍不支持把缠论状态门部署到实盘。

## 口径

本报告把超额收益放在绝对收益之前。周主动收益定义为
`net_return_FC - net_return_comparator`；TE、IR 与 HAC 都使用这条配对周序列。
相对净值严格定义为 `NAV_FC / NAV_comparator`，不对周主动收益直接复利。

“累计收益差”和“相对财富收益”不可混用：

- 累计收益差 = FC 累计收益 − 对照累计收益，单位是百分点；
- 相对财富收益 = `NAV_FC / NAV_comparator - 1`。

F 与 FMA 都是冻结研究对照，不是市场指数，因此这里的“超额”不是市场 alpha。
FC − F 衡量门控总机制，包含候选选择、欠配、现金暴露和差异成本。

## 周均主动收益诊断

| 项目 | 验证段周均 |
| --- | ---: |
| 暴露/现金效应 | -13.61 bps |

| 毛主动收益 | -22.04 bps |
| 差异成本优势 | +6.10 bps |
| 净主动收益 | -15.94 bps |

暴露效应按每周 `(FC 暴露 − F 暴露) × F 毛收益` 计算。选择/门控残差只是保持恒等式
成立的描述性诊断，不是因果 alpha；空槽收益按 0 处理。FC 的低换手确实带来成本优势，
但不足以抵消毛主动收益的负值。

## 数据与边界

- 净收益使用固定 0.5% 现金缓冲、买 15bps、卖 25bps；空槽为 0 收益现金代理。
- 历史验证段已被研究过程看过，不是独立 OOS。
- qfq 开盘只是路径代理，缺少完整集合竞价、停复牌、公司行为、退市终值和逐日账户会计。
- 当前资产没有沪深 300、中证 500/1000 等外部全收益指数，禁止写成“市场超额”。
- Stage 3 正式前瞻样本仍为 0/52；本报告不修改 Stage 2/3 身份、账本或授权状态。
