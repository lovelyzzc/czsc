# 横截面因子 × 缠论入场时机 Pilot V2（预注册，待干净数据）

## 1. 定位与状态

V2 是对 V1 `REJECT_OR_REWRITE` 的结构性重写，不是对 V1 历史曲线继续调参。V1 引擎、
协议和产物保持冻结；V2 另建代码、协议、数据门和前向日志。

当前机器状态固定为 `LOCKED_PENDING_CLEAN_DATA`。本地只有会被后续公司行为改写的前复权
日线、近似 PIT 的名称变更和被最终长度过滤过的股票池，所以历史运行只能标记
`CONTAMINATED_STRESS_ONLY`。未通过数据门时，程序必须返回
`INVALID_DATA_OR_ENGINEERING` 或 `FORWARD_COLLECTION_REQUIRED`，不得输出“alpha 通过”。

本协议冻结于 2026-07-17。机器真源是 `xs_chan_protocol_v2.json`；本文件解释经济含义。
此外，完整成交/公司行为/统计重放引擎尚未通过工程门，因此即使未来装入合格数据，正式链也必须等
`engineering.all_passed=true` 由验证器推导后才能初始化，不能由研究人员手填。
工程门逐项包括状态重算、特征 prefix、原始响应对账、停牌与采集缺口区分、日历与账本绑定、
成交/公司行为/统计重放、artifact 语义验证和外部可信时间锚；任何一项缺失都不得启动确认链。

## 2. 唯一确认性主规格

- 每个完整交易周最后一个 session 收盘决策，下一交易 session 开盘执行；未完成交易周不提前决策。
- 50 个等权槽位，预留 0.5% 现金，不加杠杆。受阻卖出继续占用槽位。
- 新股票从当期排名补入；上期原因子目标中仍合格且当期排名不超过 75 的股票优先保留，
  排名超过 75 或失去资格才退出。这是“持有 50、退出线 75”，不是持有 Top 75。
- 不运行 N=20/30/100、退出线 50/100 等网格。50/75 是降低极端集中和换手的先验设计，
  不是 V1 已证明的最佳参数。

因子仍只有一个主假设：

1. `mom_120_20 = log(P_adj[t-20]) - log(P_adj[t-120])`；
2. `lowvol_60 = -std(log_return_adj, 60, ddof=1)`；
3. 两腿各 50%，1%/99% winsor；
4. 每个决策日分别用排序后的 PIT 行业哑变量和标准化 `log(自由流通市值)` 做 OLS 残差化，
   再将残差转为百分位排名并等权合成。

两个分量必须分别报告，但不得根据 V1 中 low-vol 较好而晋级单腿，也不得反转 momentum。
因子价格物理使用 `未复权 close × 当日 adj_factor`；成交、整手、成本和净值使用未复权
OHLC。未来公司行为追加后，历史特征和决策必须逐字段不变。

所有 20/60/120 窗口都按交易所 market session 计数。停牌 session 的特征价格沿用最后已知
复权价、成交额记零；因此 ADV20 包含停牌日，而不是取“最近 20 个有成交日”。最近 60 个 session
至少 57 日有效成交的资格门另行计算。缠论状态使用 `raw OHLC × 同日 adj_factor` 的有效成交 bar，
首 120 根显式为状态 0。

## 3. 股票池与数据门

每个时点只允许纳入：已上市至少 250 个市场 session、尚未退市、非 ST、最近 60 个市场
session 至少 57 日有效成交、ADV20 不低于 5,000 万元且 PIT 字段完整的股票。科创板和
北交所继续排除；缺 PIT 行业、自由流通股本、复权因子或官方涨跌停价一律不合格。
`board` 必须先规范化为 `MAIN/CHINEXT/STAR/BSE` 四值之一，未知或源端原始标签不得直接进入筛选。

正式数据 bundle 必须内容寻址且不可覆盖，manifest 逐文件记录 SHA256、schema、行数、
日期范围、源接口参数和抓取时间。至少包括：

- 正式交易所日历；
- 含 L/D/P、上市日和退市日的 security master；
- 名称变更/ST 有效区间及抓取时间；
- 未复权 `daily`；
- 每日 `adj_factor`；
- 含 `free_share` 的 `daily_basic`；
- 盘前公布的 `stk_limit(up_limit/down_limit)`；
- 带 `in_date/out_date` 的申万行业成员；
- 现金分红、送转/拆并股、配股、合并和退市对价等公司行为；
- 按 L/D/P 和 API 分区记录 expected/received/missing 数量及请求/响应 hash 的全市场对账；
- 独立的 `symbol,dt,regime` 0–10 状态投影；
- 100 只 × 20 个截断点、2,000 次零差异的状态审计报告。

公司行为类型只允许 `cash_dividend`、`share_change`、`rights_issue`、`delist_cash`、
`delist_share`、`delist_writeoff` 六类；全市场对账分区固定为 security master 的 L/D/P、
raw bundle 股票集合和公司行为覆盖集合。新增类型或分区必须另立协议，不能运行时解释。

数据门从 manifest、物理 schema、唯一键、日期覆盖、全市场对账和状态审计自动推导，禁止手填一个
`ready=true` 绕过。所有 `source_asof/ingested_at` 必须不晚于 manifest 或当周 snapshot 的冻结时间；
只保留幸存股票、当前行业回填或未来抓取时间都会关门。数据和工程门全绿后只允许启动前向记录；完成 52 周后，
`confirmatory_oos` 才能由日志验证器自动变为 true。

## 4. 缠论时机与对照

缠论臂 `FC` 只保留一个假设：在相同的缓冲后因子 50 名单中，状态 `{5,6,7,8}` 只对
实际尚未持有的新仓放行；缺状态拒绝；不回填第 51 名以后股票。已有股票若仍是因子目标，
不因门关闭被强平。买入失败的股票下周仍是新仓，必须重新过门。

固定 MA 安慰剂 `FMA` 使用 `P_adj[t] > SMA20_adj[t]`，语义与 FC 相同。禁止比较
SMA10/20/60 后挑选。

三个对照均使用连续 20 个冻结种子并报告全部分布：

- `R_match`：逐期、联合分层精确匹配 F 的 PIT 行业、自由流通市值五分位、ADV20 五分位
  和每层旧名单留存数；
- `FGR`：在同一 F 名单中精确匹配 FC 的实际旧仓留存数和新仓放行数；
- `FMGR`：同理匹配 FMA。

无法精确匹配时该期控制无效，不能扩大池子或换种子。门控配额在成本重放前冻结，gross、
1×、2×和容量压力必须重放相同身份，不能因为成本导致持仓不同后再重新抽门。
随机数由协议、arm、seed index 和决策日做 SHA256 域分离，不使用 seed 与日期整数相加。
冻结算法版本为 `xs_chan_rng_v2_sha256_seedsequence_v1`；跨 arm 或跨周不得复用随机流。

所有“实际已持有”与 gate quota 均取各 arm 的 1,000 万元、1×成本参考账本。名单外受阻卖出先占
50 个槽位，再按“缓冲名单顺序、股票代码”截断新仓，之后才冻结 FC/FMA/FGR/FMGR 身份；gross、
2×和 1 亿元容量场景只重放这些身份，不形成新的决策路径。

## 5. 成交、成本和容量

继续使用先卖后买、100 股整手、受阻卖出逐日重试、受阻买入取消、单笔最多 5% ADV、
佣金最低 5 元、历史印花税、基础滑点和平方根冲击。涨跌停不再按代码段近似，而是使用
执行日前已公布的 `stk_limit`。退出容量必须使用退出决策日已知 ADV，缺失时 fail closed，
不得沿用陈旧 ADV。

冲击固定为 `15bps × sqrt(|成交金额| / (0.01 × ADV20))`，单笔仍先受 5% ADV 上限约束。
先用原始开盘和官方涨跌停判断可成交性，再截参与率、加入滑点/冲击；冲击后越界时仅在原始开盘
可成交的前提下截到官方限价。最低佣金按“股票×方向×执行 session”的实际成交金额计算；2×成本
放大费率但不放大 5 元最低佣金。gross 移除佣金、税、过户、滑点和冲击，但保留相同限价、容量、
整手和成交约束。

除权日前开盘前先处理公司行为：现金分红入现金，送转/拆并按比例改股数；配股默认不认购，仅在
存在官方处置收入时入账，否则整期失效。退市按官方现金/换股对价结算；无可验证终值时在生效日
归零；换股退市必须同时记录非空的目标 `consideration_ts_code` 和换股比例。长期停牌在终止事件前
用最后原始收盘估值。任何缺公司行为或终值证据都使整期失效，不能
用 `dropna` 删除股票。

固定输出：零成本但仍受容量约束的 gross、1×、2×成本，以及唯一的 1 亿元初始资本容量
压力。不得搜索多个 AUM 后选择最好结果。每笔记录请求/成交/未成交名义金额和 fill ratio；
任何场景不得负现金、不得超过 50 个实际持仓。

## 6. 只追加前向验证

正式验证使用独立哈希链目录：`000000` 冻结协议、依赖闭包、种子、日历和 bundle
hash；之后 decision 与 execution 分开排他创建。decision 必须在决策日 15:00 后且下一 session 09:30 前写入，
execution 必须引用已有 decision hash。禁止覆盖、回填、缺号、分叉或在修改协议后续写旧链。
依赖闭包精确包含 data evidence、状态/特征/研究/成交/统计引擎和 replay verifier；周度 decision/execution
的引擎 hash 必须分别等于 genesis 冻结值。
execution 只能在执行 session 的 09:30（含）之后、15:00 之前写入，逾期记录不计入确认窗。

decision payload 必须绑定当周 as-of 数据 snapshot、engine、F/FC/FMA 以及三类各 20 个 seed 的控制身份、
reference holdings、ADV、状态和 MA 输入 hash；execution payload 必须绑定盘前官方 limit/raw OHLC/
公司行为 snapshot、请求/成交/未成交、费用、现金、持仓和 pending sells。空 payload、字段缺失或不变量
失败的记录不计一周。
在 artifact 语义重放器完成前，本地账本只能报告结构完整周数，`confirmatory_oos` 必须恒为 false；
合法 hash 和自报布尔值本身不是有效周期证据。

只有最早连续完整的 52 个周度 decision/execution 周期构成唯一确认窗；第 53 周以后不得重算确认结论。
正式周序列从首个合格股票数达到 50 的完整周开始，此后任一周跌破 50 即整条链 fail closed，不能另选起点。
历史压力测试不得写入该链。

## 7. 非对称判定树

1. 任一数据或工程门失败：`INVALID_DATA_OR_ENGINEERING`；
2. 少于 52 个完整周：`FORWARD_COLLECTION_REQUIRED`；
3. 对照数量、留存或平均暴露差不合格：`INVALID_CONTROL`；
4. H1 因子先检验：`F_2x − R_match_2x` 的年化主动收益、周中位数和 4 周块 bootstrap
   下界均须大于 0，HAC lag-4 单侧 t 至少 1.645，最好 10 个正主动周贡献不超过 50%；
5. H1 失败即 `REJECT_FACTOR`，缠论不得挽救因子底座；
6. H1 通过后才检验 H2：gross `FC−FGR` 为身份主比较，同时必须在 2×成本后为正，
   且相对 FGR 与固定 FMA 均通过同一方向和统计门；FC 相对 F 至少改善 IR 或最大回撤之一；
7. 经济门通过但统计门未通过只记 `INCONCLUSIVE`，不得看结果后延长确认窗；
8. 全部通过也只到 `FORWARD_EVIDENCE_PASSED_SHADOW_ONLY`，解锁 shadow/capacity 验证，
   不直接上线。

20 个 seed 先逐周做无选择等权平均，再计算时间序列统计。HAC 使用 Bartlett 权重 Newey–West lag 4；
bootstrap 使用 circular 4 周块、20,000 次、seed 20260717、线性 5% 分位。Top10 集中度是最大 10 个
正主动周之和除以全部正主动周之和（无正周记 0）。任何 invalid period 使整个 52 周窗无效，不删除、
替换或延长；IR 为 `sqrt(52)×周均值/样本标准差(ddof=1)`，最大回撤用 NAV 相对历史峰值的最小跌幅。
样本标准差为零时该比较无效；winsor 分位数与 bootstrap 分位数均固定使用 `linear` 插值。
机器协议只注册七个比较：`F_2x−R_match_2x`、FC 相对 FGR 的 gross/2×、FC 相对 FMA 的
gross/2×、FMA 相对 FMGR 的 gross/2×；其他比较不得进入确认性统计。

任何改因子权重、窗口、持仓数、缓冲、状态子集、随机种子、起止日期或统计量的方案，必须
另立未来协议与新哈希链；不得覆盖本协议。
