# 横截面因子 × 缠论探索研究 Stage 1

本研究与冻结的 V2.1 确认协议完全分离。V2.1 的协议、结果、状态和账本均不得修改，也不会启动前向确认链。
机器规格为 `xs_chan_exploration_stage1.json`，研究身份固定为
`xs_chan_exploration_stage1_20260727`，模式固定为 `EXPLORATORY_ONLY`。

## 研究问题

第一阶段只回答六类问题：

1. 历史收益可由市场、规模、申万一级行业、低波动和动量解释多少；
2. 状态 5、6、7、8 分别覆盖多少候选，后续收益、20 日路径回撤、身份换手和成交能力如何；
3. 进入冻结因子池后收益不高的股票，在决策时可见特征上有什么共同点；
4. 状态身份随机化、行业与规模匹配随机组、固定信号延迟和 SMA20 简单趋势门能否复现结果；
5. 哪些实验失败或数据不足；
6. 下一轮最值得研究的三个可证伪假设是什么。

## 固定边界

- 样本固定为当前压力缓存可覆盖的 2022-01-01 至 2026-07-08。
- 决策日是每个 `W-FRI` 周期最后一个全市场观测 session，下一全市场 session 开盘入场。
- 主要观察窗固定为 5 个全市场 session，诊断窗固定为 20 个。
- 信号延迟固定为 0、1、3、5 个 session。
- 因子、50/75 缓冲、状态集合、SMA20、随机次数和所有失败定义都在运行前登记。
- 不搜索权重、阈值、窗口、状态子集、延迟或“最佳”变体。
- 所有计划实验与运行失败都写入同一实验登记表；失败结果不得删除。

## 数据含义

历史 qfq 行情和 V2 状态缓存只允许用于污染压力研究。每日自由流通股本与申万一级行业成员关系从数据源重新
提取并缓存，但当前数据仍缺少 V2.1 正式要求的不可变原始响应、官方停复牌、集合竞价、完整公司行为与退市
终值证据。因此：

- 缺少下一 session 开盘或终值的样本保持缺失，不猜测成交或归零；
- “成交能力”只是基于下一开盘是否存在、ADV20 和 5% 参与率的代理，不等于真实可成交；
- 归因是事后描述，不是因果证明；
- 所有结果只能生成新假设，不能确认 alpha 或授权实盘。

## 运行

```bash
uv run --no-sync python scripts/xs_chan_exploration_stage1.py fetch-reference-data
uv run --no-sync python scripts/xs_chan_exploration_stage1.py run
```

输出固定写入 `scripts/_output/xs_chan_exploration_stage1/`。`report.md` 是人类可读报告，
`summary.json` 是机器摘要，`experiment_registry.json` 保留全部实验状态，其余 parquet 保留逐周或逐样本证据。
